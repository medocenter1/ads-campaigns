# Instagram technology outreach research

**Snapshot date:** 2026-11-03  
**Activity window:** 2026-10-03 through 2026-11-03 (inclusive)  
**Scope:** European countries and the United States.

## Inclusion rules

A profile is listed only when both checks were supported by public evidence:

1. Its public profile or recent content is about technology, software, apps, AI tools, consumer electronics, gadgets, computers, or a closely related technology topic.
2. At least one public Instagram post was observed within the activity window above.

Country assignment follows the country attribution in the cited creator directory, the publisher's official/about page, or the creator's public bio. The language field describes the language observed in the account's content, not necessarily the creator's native language.

## Duplicate handling

Profile URLs are normalized to `https://www.instagram.com/<handle>/`. Handles are compared case-insensitively across **all country files** before insertion. A profile is stored in one country file only. The full existing country-file set was reviewed before this update.

## Verification caveats

Public creator directories and Instagram mirrors can lag or disagree. The dated public post is the activity proof; country and technology focus are cross-checked separately. Some directory ranking pages include inactive, irrelevant, or vaguely classified accounts, so rank alone is never treated as evidence of recent posting. Empty country files are intentional: no profile was added without adequate evidence for the activity, subject and country/language requirements. This is a manually verified shortlist, not an exhaustive census. Recheck activity before outreach.
