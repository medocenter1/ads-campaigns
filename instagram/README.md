# Instagram technology outreach research

**Snapshot date:** 2026-11-03  
**Activity window:** 2026-10-03 through 2026-11-03 (inclusive)  
**Scope:** European countries and the United States.

## Inclusion rules

A profile is listed only when both checks were supported by public evidence:

1. Its public profile or recent content is about technology, software, apps, AI tools, consumer electronics, gadgets, computers, or a closely related technology topic.
2. At least one public Instagram post was observed within the activity window above.

Country assignment follows the country attribution in the cited creator directory, the publisher's official/about page, or the creator's public bio. The language field describes the language observed in the account's content, not necessarily the creator's native language.

## Duplicate handling

Profile URLs are normalized to `https://www.instagram.com/<handle>/`. Handles are compared case-insensitively across **all country files** before insertion. A profile is stored in one country file only. Before this update, all 51 country files were fetched and checked. Nine files contained 143 profile links (all distinct), while 42 files contained no Instagram profile links. The previous README still listed `why.cgi`, but its Denmark file had been inadvertently emptied in V 0.53; that existing entry has been restored using its retained V 0.52 evidence. The new handles `notionhq` and `claudeai` were compared case-insensitively with profile handles across all 51 country files and were absent. The corrected country files and central shortlist now contain **146 unique profiles**.
