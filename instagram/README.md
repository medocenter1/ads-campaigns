# Instagram technology outreach research

**Snapshot date:** 2026-11-03  
**Activity window:** 2026-10-03 through 2026-11-03 (inclusive)  
**Scope:** European countries and the United States.

## Inclusion rules

A profile is listed only when both checks were supported by public evidence:

1. Its public profile or recent content is about technology, software, apps, AI tools, consumer electronics, gadgets, computers, or a closely related technology topic.
2. At least one public Instagram post was observed within the activity window above.

Country assignment follows the country attribution in the cited creator directory or creator bio. The language field describes the language observed in the account's content, not necessarily the creator's native language.

## Duplicate handling

Profile URLs are normalized to `https://www.instagram.com/<handle>/`. Handles are compared case-insensitively across **all country files** before insertion. A profile is stored in one country file only.

## Verification caveats

Public creator directories and Instagram mirrors can lag or disagree. The date of a directly observed recent post takes precedence for the activity check; country and topic are cross-checked separately. Empty country files are intentional: at this snapshot, no profile was added unless both the topic/country and recent-post requirements could be supported. An empty file does not mean that no suitable creators exist in that country.
